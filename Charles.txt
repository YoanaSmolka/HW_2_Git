Настройка Charles Proxy с нуля состоит из нескольких последовательных шагов: установка, базовая конфигурация, добавление сертификатов для расшифровки HTTPS и настройка прокси на целевом устройстве (смартфоне или самом ПК).
Ниже приведена пошаговая инструкция.
------------------------------
## Шаг 1. Установка и запуск на ПК

   1. Cкачайте Charles с официального сайта и установите его.
   2. Запустите программу. На Windows при первом запуске может появиться запрос от брандмауэра (Firewall) — разрешите доступ.

------------------------------
## Шаг 2. Включение логирования трафика на ПК
Чтобы Charles начал перехватывать трафик с вашего компьютера:

* В верхнем меню выберите Proxy -> Windows Proxy (или macOS Proxy).
* После этого в левой панели (Structure) начнут появляться запросы от запущенных на ПК программ.

------------------------------
## Шаг 3. Настройка расшифровки HTTPS (SSL Proxying)
По умолчанию Charles видит HTTPS-трафик как зашифрованные нечитаемые символы. Чтобы это исправить:

   1. Перейдите в Proxy -> SSL Proxying Settings...
   2. Перейдите на вкладку SSL Proxying и поставьте галочку Enable SSL Proxying.
   3. В блоке Include нажмите кнопку Add и заполните поля:
   * Host: * (звездочка означает «все сайты»)
      * Port: 443
      * Нажмите OK, затем снова OK.
   
------------------------------
## Шаг 4. Установка корневого сертификата на ПК
Без этого шага браузеры будут ругаться на небезопасное соединение.

* Для macOS:
1. Перейдите в Help -> SSL Proxying -> Install Charles Root Certificate.
   2. Откроется «Связка ключей» (Keychain Access). Найдите сертификат Charles Proxy... (он будет с красным крестиком).
   3. Кликните по нему дважды, раскройте пункт Trust (Доверие) и выберите Always Trust (Всегда доверять) для всех параметров.
* Для Windows:
1. Перейдите в Help -> SSL Proxying -> Install Charles Root Certificate.
   2. Нажмите Установить сертификат -> Выберите Текущий пользователь -> Далее.
   3. Выберите пункт Поместить все сертификаты в следующее хранилище -> нажмите Обзор -> выберите Доверенные корневые центры сертификации -> ОК -> Далее -> Готово.

------------------------------
## Шаг 5. Настройка прокси на мобильном телефоне (iOS / Android)
Чтобы перехватывать трафик со смартфона, он должен находиться в одной Wi-Fi сети с вашим компьютером.
## 1. Узнайте IP-адрес компьютера
В Charles перейдите в Help -> Local IP Address. Запишите или запомните первый IP-адрес в списке (например, 192.168.1.50). Порт по умолчанию — 8888.
## 2. Настройка Wi-Fi на телефоне

* На iOS: Зайдите в Настройки -> Wi-Fi -> нажмите на иконку (i) рядом с вашей сетью -> прокрутите вниз до Настройка прокси -> выберите Вручную.
* На Android: Зайдите в Настройки -> Wi-Fi -> зажмите имя сети (или нажмите «Изменить сеть») -> раскройте Дополнительно -> Прокси -> выберите Вручную.

Заполните поля:

* Сервер / Имя хоста: IP-адрес вашего ПК (из п. 1)
* Порт: 8888
* Сохраните настройки.

Важно: В этот момент на ПК в программе Charles появится всплывающее окно с запросом на подключение нового устройства. Обязательно нажмите Allow (Разрешить).

## 3. Установка сертификата на телефон

   1. Откройте браузер Safari (на iOS) или Chrome (на Android) и перейдите по адресу: chls.pro/ssl
   2. Начнется скачивание файла сертификата.


* Для iOS:
1. Перейдите в Настройки -> Профиль загружен -> нажмите Установить в правом верхнем углу.
   2. После установки перейдите в Настройки -> Основные -> Об этом устройстве -> Доверие сертификатам (в самом низу) -> включите тумблер напротив сертификата Charles.
* Для Android:
1. Перейдите в Настройки -> Безопасность -> Шифрование и учетные данные -> Установка сертификатов -> Сертификат CA (названия пунктов могут отличаться в зависимости от прошивки).
   2. Выберите скачанный файл сертификата и подтвердите установку.

------------------------------
## Как проверить, что всё работает?
Откройте любое приложение или сайт на телефоне. В Charles в левой панели Structure вы должны увидеть новые папки с адресами этих сайтов, а внутри запросов (вкладка Contents) — понятный текст (JSON/HTML) вместо непонятных кодировок.
