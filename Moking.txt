
Подмена данных (Mocking / Перехват)

В Charles есть два основных способа подменить ответ сервера: Map Local (когда сервер сразу возвращает готовый файл с вашего ПК) и Rewrite (когда Charles «на лету» меняет заголовки, статус-коды или часть текста в реальном ответе сервера).

Способ А. Map Local (Подмена ответа готовым файлом)

Идеально подходит, если вам нужно полностью заменить большой JSON-ответ от сервера на свой собственный.
1. Найдите нужный запрос в левой панели (Structure).
2. Нажмите по нему правой кнопкой мыши и выберите Save Response...
3. Сохраните этот файл на компьютер (в формате .json или .txt).
4. Откройте сохраненный файл в любом текстовом редакторе и измените данные так, как вам нужно для теста.
5. Вернитесь в Charles, снова нажмите правой кнопкой мыши по этому же запросу и выберите Map Local...
6. В открывшемся окне Charles автоматически заполнит протокол, хост и путь. Вам нужно только в самом низу в поле Local path нажать Choose и выбрать ваш измененный файл.
7. Нажмите OK. Теперь при каждом таком запросе приложение будет получать данные из вашего локального файла.
Чтобы отключить подмену, перейдите в Tools -> Map Local... и снимите галочку с правила.

Способ Б. Rewrite (Изменение данных «на лету»)

Удобно, если нужно поменять только один параметр (например, статус-код с 200 OK на 500 Error, имя пользователя или заголовок авторизации).
1. В верхнем меню перейдите в Tools -> Rewrite...
2. Поставьте галочку Enable Rewrite и нажмите кнопку Add в левом нижнем столбце (создастся новый набор правил).
3. В правом столбце Location нажмите Add, чтобы указать, для какого сайта применить подмену. Заполните поле Host (например, ://example.com) и нажмите OK. Если оставить поля пустыми, правило применится ко всем сайтам.
4. В самом нижнем блоке правил нажмите Add. Откроется окно настройки замены:
	• Type: Выберите, что именно меняем. Например, Body (текст ответа), Response Status (код ответа) или Header (заголовки).
	• Where: Выберите Response (чтобы менять то, что приходит от сервера) или Request (чтобы менять то, что уходит на сервер).
	• Match (Что ищем): Введите значение, которое присылает сервер сейчас (например, "status": "active").
	• Replace (На что меняем): Введите новое значение (например, "status": "banned").
5. Нажмите OK, затем Apply.
